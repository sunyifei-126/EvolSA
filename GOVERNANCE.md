# Governance

EvolSA is maintained in the open. Maintainers merge changes based on technical merit,
reproducibility, safety, compatibility, and evidence quality—not benchmark score alone.

Changes to public schemas, protected surfaces, promotion semantics, or evidence verification
require a design note, migration plan, regression tests, and maintainer approval. The same pull
request must not both weaken a safety threshold and introduce an operator that depends on the
weaker threshold.

Stable community operators require a passport, minimal reproduction, matched-budget report,
known failures, and license provenance. Negative results remain valuable registry artifacts.
