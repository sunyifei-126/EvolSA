# Roadmap

## v0.1 — Executable bounded-RSI loop

- task/operator/model protocols;
- four seed operators;
- content-addressed artifacts and a local integrity-only event hash chain;
- Experience Card/Board and operation-conditioned retrieval;
- quality/progress/novelty search;
- trace-to-passport foundry;
- paired bootstrap lab, promotion gate, registry rollback;
- deterministic CPU demo and static lineage report.

The v0.1 items are research-reference capabilities, not production security guarantees. The
local hash chain is not producer authentication, public sealed tasks are not secrets,
`SubprocessSandbox` is not a container boundary, and only callback-free L0 prompt-template
operators can be persisted and restored. Python callbacks and adapters are trusted in-process
code.

## v0.2 — Operator Foundry

- schema-validated L0/L1 compilers;
- richer applicability calibration and failure mining;
- tabular-lite, repo-repair-lite, and prompt-lite packs;
- container sandbox adapter and signed evidence attestations.

Production deployments must not wait on a version label as a security argument: they require a
separately configured hardened container/VM, an evaluator outside the agent/search process, and
an externally signed and retained run root.

## v0.3 — Learned Controller

- contextual bandit scheduling;
- information-gain and cost-aware acquisition;
- cross-task transfer matrix and retention suite.

## v0.4+ — Multi-generation research

- scheduler and memory-policy passports;
- asynchronous evaluation with unbiased reservations;
- meta-operator evolution under the same external gate;
- reproducible improvement-acceleration reports.
